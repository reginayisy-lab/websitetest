| 경로 | 내용 |
|---|---|
| `index.html` | 랜딩페이지 마크업 |
| `assets/css/style.css` | 스타일 |
| `assets/js/main.js` | 애니메이션·스크롤 효과 |
| `assets/js/form.js` | 문의 폼 검증·전송 (전송은 5단계에서 연결) |
